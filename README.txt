# Gesture-Controlled Zombie Survival Game

A 3D zombie survival game developed using **Unity**, featuring real-time hand gesture recognition through **Python, OpenCV, and MediaPipe**. The project explores the integration of computer vision with interactive gameplay, allowing players to perform in-game actions using hand gestures detected through a webcam.

Players must navigate an isolated island and an abandoned castle while avoiding zombies, using environmental sound distractions and stealth-based mechanics to survive.

## 🎮 Project Overview

The game combines third-person survival gameplay, gesture-based interaction, and AI-driven zombie behavior to create an interactive gaming experience.

The player begins their journey by arriving at an isolated island, navigating through a forest, and eventually exploring a large, abandoned castle inhabited by zombies.

### Key Features

- **Real-Time Hand Gesture Recognition:** Detects hand gestures using MediaPipe and OpenCV through a webcam.
- **Gesture-Controlled Interactions:** Maps recognized gestures to in-game actions through communication between Python and Unity.
- **Object Pickup and Throwing:** Supports gesture-based object interactions, with proximity restrictions for pickup mechanics.
- **Zombie AI:** Uses Unity's NavMeshAgent and Animator systems to control zombie movement and behavior.
- **Sound-Based Distractions:** In-game sounds, including dropped objects, can attract zombies and create opportunities for stealth.
- **Third-Person Gameplay:** Explore an island environment, forest areas, and an abandoned castle.
- **Animation and Gameplay Integration:** Connects player interactions, object mechanics, and zombie behavior to the gameplay experience.

## 🧠 System Architecture

The project uses a Python-based computer vision module alongside the Unity game engine.

```text
          Webcam Input
               |
               v
       Python Application
               |
               v
     OpenCV + MediaPipe
               |
               v
       Hand Gesture Detection
               |
               v
       UDP Communication
          Port: 5052
               |
               v
       Unity GestureReceiver
               |
               v
    GestureActionController
               |
               v
       In-Game Interactions
```

The Python application processes webcam input, detects hand landmarks, and identifies supported gestures. The detected gesture information is transmitted to Unity over UDP, where C# scripts interpret the input and trigger corresponding gameplay actions.

## 🧟 Gameplay Mechanics

### Gesture Recognition
The system uses MediaPipe hand landmarks to identify hand configurations, such as an open palm and a fist. These gestures serve as inputs for supported gameplay interactions.

### Object Interaction
The player can interact with designated objects through gesture-based controls. The intended pickup mechanic includes a proximity check, allowing interaction only when an object is within approximately one metre of the player.

### Zombie Behavior
Zombies use Unity's navigation and animation systems to follow the player and respond to environmental distractions. Sounds generated by dropped or thrown objects can redirect zombie attention, supporting stealth-oriented gameplay.

### Environment and Story
The game follows a third-person survival concept set across an isolated island, a forest, and an abandoned castle. Environmental exploration, zombie encounters, and sound-based distractions form the core gameplay loop.

## ⚙️ Setup and Installation

### Prerequisites

- Unity Editor compatible with the project's Unity version
- Python 3.10.11
- A webcam
- Python package manager (`pip`)

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

Replace the URL with your actual GitHub repository URL.

### 2. Set Up the Python Environment

Navigate to the gesture recognition module directory:

```bash
cd GestureControlProject
```

Create and activate a virtual environment.

**Windows PowerShell:**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Install the required Python packages:

```bash
pip install opencv-python mediapipe==0.10.14
```

### 3. Configure Unity

1. Open the Unity project using Unity Hub.
2. Allow Unity to import the project assets and compile the C# scripts.
3. Verify that the `GestureReceiver` and `GestureActionController` scripts are attached to the appropriate GameObjects.
4. Ensure the Unity receiver listens on UDP port `5052`, matching the Python application's configuration.
5. Check that the required character models, animations, environment assets, and zombie navigation components are configured.

### 4. Run the Project

1. Start the Python gesture recognition application.
2. Allow webcam access when prompted.
3. Run the Unity scene containing the player and gesture receiver.
4. Perform the supported hand gestures in front of the webcam.
5. Verify that the detected gestures trigger the corresponding in-game interactions.

**Note:** The Python script and Unity project must use matching network settings. Your operating system's firewall must also allow the required local UDP traffic.

The exact launch commands depend on the filenames and directory structure included in the repository.
